# QA ProcessedDocs

QA’s analysis of the frozen inputs. See [QA](../README.md) for this phase and the [pipeline README](../../README.md) for the shared rules.

## What to put here

After reading [3-1_InputDocs](../3-1_InputDocs/README.md), record which files apply to QA and which parts of each file apply. Note anything the workflow must keep, ignore, or resolve. Write that analysis here in files you can revise as understanding changes.

This folder is the phase’s interpretation. It is not a second copy of the inputs and not the QA deliverable.

## What not to do

- Do not edit InputDocs. Refer to them by filename.
- Do not run the BMAD workflow here, and do not leave workflow scratch here.
- Do not put finished test plans, cases, or acceptance checks here.

## Where the workflow reads and writes

Read InputDocs and the notes in this folder. Run the QA BMAD workflow in [3-3_Working](../3-3_Working/README.md). Write finished test plans, cases, and acceptance checks to [3-4_OutputDocs](../3-4_OutputDocs/README.md).
