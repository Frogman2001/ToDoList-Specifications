# QA Working

Where QA runs this phase’s BMAD workflow. See [QA](../README.md) for this phase and the [pipeline README](../../README.md) for the shared rules.

## What to put here

Drafts, memlogs, intermediate notes, and other scratch the workflow produces while it turns upstream specifications into test plans, cases, and acceptance checks. Work from [3-1_InputDocs](../3-1_InputDocs/README.md) and [3-2_ProcessedDocs](../3-2_ProcessedDocs/README.md).

When the workflow finishes, write those deliverables to [3-4_OutputDocs](../3-4_OutputDocs/README.md). Leave the working files here.

## What not to do

- Do not treat files here as the phase deliverable. Later readers must not copy from this folder.
- Do not write workflow output into InputDocs or ProcessedDocs.
- Do not edit Development OutputDocs, Architecture OutputDocs, the PO originals, or the InputDocs snapshots from this workflow.

## Where the workflow reads and writes

Read InputDocs and ProcessedDocs. Write scratch here. Write only finished test plans, cases, and acceptance checks to OutputDocs.
