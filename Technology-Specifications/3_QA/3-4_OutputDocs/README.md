# QA OutputDocs

Finished QA deliverables. See [QA](../README.md) for this phase and the [pipeline README](../../README.md) for the shared rules.

## What to put here

Completed test plans, cases, and acceptance checks. These are the documents this phase hands off. There is no later phase in this tree.

## What not to do

- Do not put drafts, memlogs, or other scratch here. Those stay in [3-3_Working](../3-3_Working/README.md).
- Do not edit Architecture or Development OutputDocs from this folder. QA already copied what it needed into [3-1_InputDocs](../3-1_InputDocs/README.md).
- Do not revise a finished file here in place once someone outside this phase is using it. A new finished version is a new file, or a deliberate replacement by QA before that use.

## Where the workflow reads and writes

The workflow reads [3-1_InputDocs](../3-1_InputDocs/README.md) and [3-2_ProcessedDocs](../3-2_ProcessedDocs/README.md), runs in [3-3_Working](../3-3_Working/README.md), and writes the finished result here.
