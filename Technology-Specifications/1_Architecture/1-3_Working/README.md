# Architecture Working

Where the architect runs the BMAD architecture workflow. See [Architecture](../README.md) for this phase and the [pipeline README](../../README.md) for the shared rules.

## What to put here

Drafts, memlogs, intermediate notes, and other scratch the workflow produces while it runs. Work from [1-1_InputDocs](../1-1_InputDocs/README.md) and [1-2_ProcessedDocs](../1-2_ProcessedDocs/README.md).

When the workflow finishes, write the architecture document to [1-4_OutputDocs](../1-4_OutputDocs/README.md). The epics handoff is drafted here too, then copied to OutputDocs once it is accepted. Leave the working files here.

## What not to do

- Do not treat files here as the phase deliverable. Later phases must not copy from this folder.
- Do not write workflow output into InputDocs or ProcessedDocs.
- Do not edit the PO originals or the InputDocs snapshots from this workflow.

## Where the workflow reads and writes

Read InputDocs and ProcessedDocs. Write scratch here. Write the finished architecture document to OutputDocs. The accepted epics handoff is [epics.md](../1-4_OutputDocs/epics.md). The working copy and its memlog stay in [epics-ToDoList-2026-11-06](epics-ToDoList-2026-11-06/epics.md).
