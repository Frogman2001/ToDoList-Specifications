- (constraint) One back end serves two clients, web and Android. Binds project 1. Prevents a second back end or a read-only phone client.
- (constraint) Sign-in is Google only. A user sees and changes only their own items, and no item data is available without signing in. Prevents per-client accounts and a shared or anonymous item store.
- (constraint) Lists are not stored. An item has description, state, detail, due date, completed date, and a position among items with the same due date. Views are computed. Prevents a stored Today list or week list.
- (constraint) Due and completed dates are calendar dates with no time zone. Clients compute Today, week, and order from the device date. The same items and the same date produce the same view and order on web and Android. Prevents a server-local midnight and client-specific sort rules.
- (constraint) The week starts Monday, held in one config value behind a property. Next week is the following Monday. Next month is the first of the next month. Prevents each client hard-coding a different week boundary.
- (constraint) Setting done records the completed date and does not change the due date. Leaving done clears the completed date. A drag across a day reschedules to that day and lands where it is dropped; in Today, dragging an overdue item into today's items sets the due date to today. A move to another date puts the item at the end of that date. Prevents clients from inventing different completion and reorder effects.
- (constraint) Moving several items at once is web only. Every other project-1 behavior exists on both clients. Prevents a second platform-only feature.
- (constraint) Project 1 has no offline mode and is not designed for scale. It is deployed to production. Prevents a sync layer or a scale-out design in this project.
- (constraint) Visual values are named tokens, and the web theme must be swappable without hard-coded colors in behavior. Prevents each screen embedding its own palette.
- (constraint) Android opens on Add new. Web opens on the week that contains today. Signed-out Android can hold an add and then ask to sign in. Signed-out web shows sign-in before the list.
