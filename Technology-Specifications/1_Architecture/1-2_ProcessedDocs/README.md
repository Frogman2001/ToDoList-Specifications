# Architecture ProcessedDocs

The architect’s analysis of the frozen inputs. See [Architecture](../README.md) for this phase and the [pipeline README](../../README.md) for the shared rules.

## What to put here

After reading [1-1_InputDocs](../1-1_InputDocs/README.md), record which files apply to the architecture and which parts of each file apply. Note anything the workflow must keep, ignore, or resolve. Write that analysis here in files you can revise as understanding changes.

This folder is the phase’s interpretation. It is not a second copy of the inputs and not the architecture deliverable.

## What not to do

- Do not edit InputDocs. Refer to them by filename.
- Do not run the BMAD workflow here, and do not leave workflow scratch here.
- Do not put the finished architecture document here.

## Where the workflow reads and writes

Read InputDocs and the notes in this folder. Run the architecture BMAD workflow in [1-3_Working](../1-3_Working/README.md). Write the finished document to [1-4_OutputDocs](../1-4_OutputDocs/README.md).
